ABOUT THE PROJECT

Turning Shopping Behavior into Actionable Predictions

Shopy Wise is a machine learning-based customer purchase prediction system that analyzes browsing and session-related behavior from online shoppers. The system helps predict whether a shopping session is likely to result in a purchase.

MACHINE LEARNING

Models Used

Shopy Wise evaluates multiple classification algorithms and compares their performance using standard evaluation metrics.

01

Logistic Regression

A classification algorithm used to estimate the probability of a customer making a purchase.

Accuracy: 88.94%
02

K-Nearest Neighbors

Predicts customer purchase behavior by comparing a session with similar observations in the dataset.

Accuracy: 87.87%
03

Decision Tree

Uses a tree-based decision structure to classify shopping sessions into purchase or no-purchase.

F1 Score: 56.41%
