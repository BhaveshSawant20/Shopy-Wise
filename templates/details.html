About SHOPY WISE

An ML-based online customer purchase prediction system designed to analyze shopping session behavior and predict whether a customer is likely to make a purchase.

Project Overview

Shopy Wise is a machine learning-based web application developed to predict online customer purchase intention. The system analyzes customer browsing and session-related attributes and uses trained classification models to determine whether the session is likely to result in a purchase.

The project demonstrates a complete machine learning workflow, starting from dataset analysis and preprocessing, followed by model training and evaluation, and finally integrating the selected model into a Flask-based web application for real-time prediction.

How Shopy Wise Works

Dataset

Customer Session Data

The system uses the UCI Online Shoppers Purchasing Intention dataset containing browsing and session behavior.

Processing

Data Preprocessing

Numerical and categorical features are processed using scaling and one-hot encoding before model training.

Prediction

Machine Learning

Logistic Regression, KNN and Decision Tree models are trained and evaluated using the prepared dataset.

Result

Purchase Prediction

The selected model predicts purchase intention and provides the predicted result along with purchase probability.

Machine Learning Models

Three classification algorithms were implemented and evaluated using the same training and testing data.

Logistic Regression

A linear classification algorithm used to estimate the probability of a binary purchase outcome.

Accuracy 88.94%

K-Nearest Neighbors

Classifies a customer session based on the behavior of similar observations in the training dataset.

Accuracy 87.87%

Decision Tree

Uses a tree-based structure of decision rules to classify whether a session is likely to generate a purchase.

F1 Score 56.41%
Model Accuracy Precision Recall F1 Score
Logistic Regression 88.94% 77.18% 41.62% 54.08%
KNN 87.87% 67.92% 42.67% 52.41%
Decision Tree 86.07% 55.28% 57.59% 56.41%
Selected Model: Decision Tree

The Decision Tree was selected for deployment because it achieved the highest Recall and F1 Score among the three implemented models in this project.
